### Phase F2 — 重写 `app/friends/page.tsx`

**What**：移除 SharkMascot import、移除 💗💙 emoji、`<img>` → `next/image`、`ocean-floor` → 普通 `pixel-card` 头部、`coral` → `accent`、补暗色变体、加 Reveal stagger。

**Why**：消除 AI-tell（emoji、img、失效类）+ 设计一致性（ocean-floor 仅 Hero）+ 暗色可用性。

**How**（关键改动）：
```tsx
import Image from 'next/image';
import { BrandMark } from '@/components/BrandMark';
import { Reveal } from '@/components/Reveal';
import { Heart, ArrowUpRight } from '@/components/icons';
// 移除 SharkMascot import

// header：
<header className="pixel-card grid items-center gap-6 rounded-3xl p-8 md:grid-cols-[1fr_220px]">
  <div>
    <h1 className="text-4xl font-black md:text-5xl">好友 / FRIENDS</h1>
    <p className="mt-4 text-lg font-bold text-slate-700 dark:text-slate-300">
      在这里发现有趣的开发者、技术创作者和开源项目。
    </p>
  </div>
  <div className="hidden justify-center md:flex">
    <BrandMark size={180} className="text-accent dark:text-accent-dark" />
  </div>
</header>

// friend 卡片：avatar 用 next/image（http avatar）或 BrandMark 占位
<div className="grid h-16 w-16 shrink-0 place-items-center overflow-hidden rounded-2xl bg-ocean-100 dark:bg-ocean-900/40">
  {friend.avatar.startsWith('http') ? (
    <Image src={friend.avatar} alt={friend.name} fill sizes="64px" className="object-cover" />
  ) : (
    <BrandMark size={28} className="text-ocean-700 dark:text-ocean-200" />
  )}
</div>
// role 颜色：text-coral → text-accent dark:text-accent-dark

// 底部 CTA：
<button className="mt-5 inline-flex items-center gap-2 rounded-xl bg-accent px-8 py-3 font-black text-white shadow-pixel transition-transform hover:-translate-y-0.5 dark:bg-accent-dark dark:text-ocean-900">
  申请加入 <ArrowUpRight size={18} />
</button>
// 移除 💙 emoji，用 ArrowUpRight 图标

// 卡片网格加 Reveal stagger：
{friends.map((friend, i) => (
  <Reveal key={friend.id} delay={(i % 3) * 60}>
    <PixelCard>...</PixelCard>
  </Reveal>
))}
```

**注意**：Image 用 `fill` 时父容器需 `relative`，给 avatar 容器加 `relative`。

## 3. Assumptions & Decisions

1. **admin 纳入范围**：虽非"前端设计优化"重点，但失效类名是技术债，必须修。仅做颜色令牌迁移，不重设计布局。
2. **ocean-floor 仅 Hero 保留**：design variance 原则，避免每页重复装饰。archive/friends/about 改用 pixel-card。
3. **avatar fallback**：friend.avatar 非 http 时用 `<BrandMark size={28}>` 占位（替代 🦈/🐱 emoji）。directus.ts 的 `'🦈'` 字符串 fallback 属数据层，保留（UI 层已用 BrandMark 兜底）。
4. **TagPill colorMap['coral'] 保留**：是数据 key 非 Tailwind 类，映射到 rose 色系，语义正确。
5. **mock-data.ts emoji 保留**：属测试数据，UI 已用 CategoryIcon 替代显示。
6. **不引入新依赖**：沿用自包含 SVG + IntersectionObserver 方案。
7. **Reveal 不滥用**：仅在页面主区块入口加，列表项加 stagger（i%3*60ms），避免每个小元素都动画。
