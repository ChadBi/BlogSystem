## 0. Design Read

**Reading this as: editorial / blog (preserve mode) for 技术读者, with a retro-pixel × ocean × geek-terminal 品牌语言, leaning toward GSAP ScrollTrigger + p5.js Perlin 流场 + Motion spring 入场。**

**Dials 调整**：`VARIANCE=7`（不变）/ `MOTION=6 → 7`（真库落地后动效更丝滑，但不过度）/ `DENSITY=4`（不变）。

**工具栈定调**：
- **p5.js 2.3.0**（instance mode，非 global）→ Hero 算法艺术背景（真 Perlin noise 流场，替代手写多频正弦近似）
- **GSAP 3.15.0 + ScrollTrigger** → 滚动进度条、Timeline 竖线 scroll-draw、Footer 鲨鱼游动、Typewriter 打字机
- **Motion 12.42.2**（`motion/react`）→ Hero 标题字符 stagger 入场、PostCard spring 入场
- **纯 CSS** → PostCard hover 倾斜（§3.B 不让用 useState 跟鼠标，固定方向 hover:rotate-1 足够）

**反 AI-slop 守则**（来自 design-taste-frontend §5）：
- 每个动效必须有动机（hierarchy / storytelling / feedback / state transition），不为动而动
- `prefers-reduced-motion: reduce` 全程守护（GSAP `matchMedia` + Motion `useReducedMotion` + p5 条件渲染）
- 不用 `window.addEventListener('scroll')`，用 GSAP ScrollTrigger / Motion useScroll
- 不全局粒子背景（影响可读性），仅 Hero 用
- Canvas 用 `pointer-events-none` + `will-change`

**algorithmic-art 哲学应用**（简短版，不创建独立 .md 文件，内嵌为本计划的算法指导）：

> **算法哲学：「Ocean Drift / 海流漂移」**
> 粒子沿不可见的 Perlin noise 流场漂移，模拟深海暗流。少量"鲨鱼"大粒子以更高速度跟随流场，留下更长的尾迹。色相由速度决定——快粒子烧亮 mint，慢粒子褪入 ocean 深蓝。算法运行至平衡态：每帧半透明覆盖造拖尾，粒子有生命周期，到达边界或寿命到期时重生。同一 seed 产生完全相同的流场（Art Blocks 模式）。reduce 模式只渲染一帧静态分布，不动画。

### Phase M2 — Hero 算法艺术背景（p5.js Perlin 流场）

**文件**：新建 [components/HeroFlowField.tsx](file:///d:/Project/BlogSystem/blog-frontend/components/HeroFlowField.tsx)，修改 [components/Hero.tsx](file:///d:/Project/BlogSystem/blog-frontend/components/Hero.tsx)

**What**：p5.js instance mode 的 Perlin noise 流场粒子背景，80 粒子沿向量场流动，5% 大粒子作"鲨鱼"（mint 色，速度更快，尾迹更长）。

**Why**：
- Hero 是首屏，算法艺术背景强化品牌海洋意象（storytelling）+ 让首屏"活"起来（hierarchy）
- algorithmic-art 技能要求"过程即美"，Perlin 流场正是过程美学的经典表达
- p5.js 原生 `noise()` 比手写多频正弦近似质量高一个档次（真 Perlin，平滑可调 octave）

**How**（p5.js instance mode 核心）：
```tsx
'use client';
import { useEffect, useRef } from 'react';
import p5 from 'p5';

// 算法艺术：Ocean Drift / 海流漂移
// - p5 Perlin noise 生成 2D 向量场
// - 80 粒子沿流场流动，半透明覆盖造拖尾
// - 5% "鲨鱼"大粒子：mint 色，速度 ×1.8，半径 ×2.5
// - seed 固定（Art Blocks 模式），同 seed 同流场
// - reduce 模式：noLoop()，只渲染一帧静态分布
export function HeroFlowField({ className }: { className?: string }) {
  const containerRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (!containerRef.current) return;
    const reduce = window.matchMedia('(prefers-reduced-motion: reduce)').matches;

    const sketch = (p: p5) => {
      const SEED = 42;
      const PARTICLE_COUNT = 80;
      const SHARK_RATIO = 0.05;
      let particles: Array<{
        x: number; y: number; vx: number; vy: number;
        life: number; maxLife: number; isShark: boolean;
      }> = [];

      p.setup = () => {
        const rect = containerRef.current!.getBoundingClientRect();
        p.createCanvas(rect.width, rect.height);
        p.noiseSeed(SEED);
        p.randomSeed(SEED);
        particles = Array.from({ length: PARTICLE_COUNT }, () => ({
          x: p.random(p.width),
          y: p.random(p.height),
          vx: 0, vy: 0,
          life: p.random(100),
          maxLife: 80 + p.random(60),
          isShark: p.random() < SHARK_RATIO,
        }));
        if (reduce) p.noLoop();
      };

      p.draw = () => {
        // 半透明覆盖造拖尾
        p.noStroke();
        p.fill(11, 88, 122, 20);  // ocean-800 半透明
        p.rect(0, 0, p.width, p.height);

        const t = p.frameCount * 0.002;
        particles.forEach((pt) => {
          // Perlin noise 向量场
          const angle = p.noise(pt.x * 0.003, pt.y * 0.003, t) * p.TWO_PI * 2;
          const speed = pt.isShark ? 1.8 : 1.0;
          pt.vx = p.cos(angle) * speed;
          pt.vy = p.sin(angle) * speed;
          pt.x += pt.vx;
          pt.y += pt.vy;
          pt.life++;

          // 重生
          if (pt.life > pt.maxLife || pt.x < 0 || pt.x > p.width || pt.y < 0 || pt.y > p.height) {
            pt.x = p.random(p.width);
            pt.y = p.random(p.height);
            pt.life = 0;
          }

          const alpha = p.sin((pt.life / pt.maxLife) * p.PI) * 0.6;
          if (pt.isShark) {
            p.fill(181, 234, 215, alpha * 255);  // mint
            p.circle(pt.x, pt.y, 5);
          } else {
            p.fill(140, 108, 255, alpha * 128);  // accent 紫，半透明
            p.circle(pt.x, pt.y, 2);
          }
        });
      };

      p.windowResized = () => {
        const rect = containerRef.current!.getBoundingClientRect();
        p.resizeCanvas(rect.width, rect.height);
      };
    };

    const instance = new p5(sketch, containerRef.current);
    return () => instance.remove();
  }, []);

  return (
    <div
      ref={containerRef}
      className={className}
      aria-hidden="true"
      style={{ pointerEvents: 'none', willChange: 'transform' }}
    />
  );
}
```

**Hero.tsx 集成**：
```tsx
import { HeroFlowField } from '@/components/HeroFlowField';

<section className="ocean-floor relative overflow-hidden ...">
  <HeroFlowField className="absolute inset-0 h-full w-full opacity-70" />
  <div className="relative z-10 grid items-center gap-8 ...">
    {/* 原内容 */}
  </div>
</section>
```

**性能**：80 粒子 + 60fps，p5 instance mode 易销毁（`instance.remove()`）。Canvas `pointer-events-none`。

### Phase M3 — 滚动进度条（GSAP ScrollTrigger）

**文件**：新建 [components/ScrollProgress.tsx](file:///d:/Project/BlogSystem/blog-frontend/components/ScrollProgress.tsx)，修改 [components/Header.tsx](file:///d:/Project/BlogSystem/blog-frontend/components/Header.tsx)

**What**：Header 底部 2px mint 色进度条，宽度随滚动百分比变化。用 GSAP ScrollTrigger scrub，比 CSS scroll-driven 兼容性更广（Safari 旧版也支持）。

**Why**：阅读进度反馈（feedback），长文必备。GSAP ScrollTrigger 是业界标准，比 CSS scroll-driven 兼容性好，且 reduce 模式可用 matchMedia 守护。

**How**：
```tsx
'use client';
import { useEffect, useRef } from 'react';
import gsap from 'gsap';
import { ScrollTrigger } from 'gsap/ScrollTrigger';

gsap.registerPlugin(ScrollTrigger);

export function ScrollProgress() {
  const barRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (!barRef.current) return;
    const mm = gsap.matchMedia();

    mm.add(
      {
        reduceMotion: '(prefers-reduced-motion: reduce)',
      },
      (ctx) => {
        const { reduceMotion } = ctx!.conditions as { reduceMotion: boolean };
        if (reduceMotion) return;  // reduce 模式不显示进度条动画

        gsap.fromTo(
          barRef.current,
          { scaleX: 0 },
          {
            scaleX: 1,
            ease: 'none',
            scrollTrigger: {
              trigger: 'body',
              start: 'top top',
              end: 'bottom bottom',
              scrub: 0.3,
            },
          }
        );
      }
    );

    return () => mm.revert();
  }, []);

  return (
    <div
      ref={barRef}
      className="h-0.5 w-full origin-left bg-mint"
      aria-hidden="true"
      style={{ willChange: 'transform' }}
    />
  );
}
```

**Header.tsx**：在 `<header>` 底部加 `<ScrollProgress />`。

### Phase M4 — Hero 标题字符 stagger + 副标题打字机

**文件**：新建 [components/Typewriter.tsx](file:///d:/Project/BlogSystem/blog-frontend/components/Typewriter.tsx)，修改 [components/Hero.tsx](file:///d:/Project/BlogSystem/blog-frontend/components/Hero.tsx)

**What**：
1. Hero 主标题"你好，我是 Shark"用 Motion 字符 stagger 弹簧入场（每个字逐个浮入）
2. Hero 副标题用 GSAP timeline 打字机效果逐字显示

**Why**：
- 标题字符 stagger → hierarchy（标题逐字聚焦，强化首屏视觉锚点）
- 打字机 → feedback（终端启动感，强化极客调性）
- Motion 的 spring 物理感比 CSS easing 更自然；GSAP timeline 控制打字机比 setTimeout 更稳

**How — Typewriter（GSAP）**：
```tsx
'use client';
import { useEffect, useRef } from 'react';
import gsap from 'gsap';

type Props = { text: string; speed?: number; className?: string; startDelay?: number };

export function Typewriter({ text, speed = 0.05, className, startDelay = 0.6 }: Props) {
  const containerRef = useRef<HTMLSpanElement>(null);

  useEffect(() => {
    if (!containerRef.current) return;
    const reduce = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
    if (reduce) {
      containerRef.current.textContent = text;
      return;
    }

    const chars = text.split('');
    containerRef.current.innerHTML = chars
      .map((c) => `<span class="tw-char" style="opacity:0">${c === ' ' ? '&nbsp;' : c}</span>`)
      .join('');

    const tl = gsap.timeline({ delay: startDelay });
    tl.to('.tw-char', {
      opacity: 1,
      duration: speed,
      stagger: speed,
      ease: 'none',
    });

    return () => {
      tl.kill();
      if (containerRef.current) containerRef.current.textContent = text;
    };
  }, [text, speed, startDelay]);

  return (
    <span ref={containerRef} className={className}>
      {text}
      <span className="ml-0.5 inline-block h-[1em] w-1.5 animate-pulse bg-mint align-middle" aria-hidden="true" />
    </span>
  );
}
```

**How — Hero 标题字符 stagger（Motion）**：

### Phase M5 — Footer 鲨鱼游动（GSAP timeline yoyo）

**文件**：[components/Footer.tsx](file:///d:/Project/BlogSystem/blog-frontend/components/Footer.tsx)，新建或复用客户端包装器

**What**：Footer 底部 SharkSwim 剪影缓慢左右游动 + 微微上下浮动（模拟鱼鳍划水）。

**Why**：storytelling（鲨鱼游出海），让 Footer 不死板。GSAP timeline yoyo + 自定义缓动比 CSS keyframes 更精细。

**How**：
```tsx
'use client';
import { useEffect, useRef } from 'react';
import gsap from 'gsap';
import { SharkSwim } from '@/components/SharkSilhouette';

export function SharkSwimAnimated() {
  const ref = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (!ref.current) return;
    const mm = gsap.matchMedia();

    mm.add('(prefers-reduced-motion: no-preference)', () => {
      const tl = gsap.timeline({ repeat: -1, yoyo: true });
      tl.to(ref.current, {
        x: 30,
        y: -3,
        duration: 4,
        ease: 'sine.inOut',
      }).to(ref.current, {
        x: -10,
        y: 2,
        duration: 3,
        ease: 'sine.inOut',
      });
      return () => tl.kill();
    });

    return () => mm.revert();
  }, []);

  return (
    <div ref={ref} style={{ willChange: 'transform' }}>
      <SharkSwim />
    </div>
  );
}
```

**Footer.tsx**：把原 `<SharkSwim />` 替换为 `<SharkSwimAnimated />`。

**注意**：`repeat: -1` 在这里是页面级装饰（非 HyperFrames 视频），允许无限循环。`matchMedia` 守护 reduce 模式。

### Phase M7 — Timeline 竖线 scroll-draw（GSAP ScrollTrigger scrub）

**文件**：[components/Timeline.tsx](file:///d:/Project/BlogSystem/blog-frontend/components/Timeline.tsx)，新建客户端子组件 `TimelineLine.tsx`

**What**：Timeline 左侧竖线的高度随滚动进度从 0 增长到 100%（scroll-draw 效果）。

**Why**：storytelling（时间线推进），视觉化"读到这里了"。GSAP ScrollTrigger scrub 比 CSS `animation-timeline: view()` 兼容性更广。

**How**：
```tsx
'use client';
import { useEffect, useRef } from 'react';
import gsap from 'gsap';
import { ScrollTrigger } from 'gsap/ScrollTrigger';

gsap.registerPlugin(ScrollTrigger);

export function TimelineLine({ className }: { className?: string }) {
  const lineRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (!lineRef.current) return;
    const mm = gsap.matchMedia();

    mm.add('(prefers-reduced-motion: no-preference)', () => {
      gsap.fromTo(
        lineRef.current,
        { scaleY: 0 },
        {
          scaleY: 1,
          ease: 'none',
          scrollTrigger: {
            trigger: lineRef.current.parentElement!,  // Timeline 容器
            start: 'top 80%',
            end: 'bottom 20%',
            scrub: 0.5,
          },
        }
      );
    });

    return () => mm.revert();
  }, []);

  return (
    <div
      ref={lineRef}
      className={className}
      style={{ transformOrigin: 'top', willChange: 'transform' }}
    />
  );
}
```

**Timeline.tsx**：原竖线 div 替换为 `<TimelineLine className="absolute left-0 top-0 h-full w-0.5 bg-accent" />`。

**注意**：reduce 模式下 `matchMedia` 不匹配，竖线保持 `scaleY: 0` 不可见 → 需要给 reduce 模式 fallback：竖线直接 `scaleY: 1` 全显示。

**修正**：reduce 模式 fallback：
```tsx
mm.add('(prefers-reduced-motion: reduce)', () => {
  gsap.set(lineRef.current, { scaleY: 1 });
});
```

## 3. Assumptions & Decisions

1. **依赖已安装**：gsap 3.15.0、motion 12.42.2、p5 2.3.0 已通过 `pnpm add` 安装成功（之前误判"沙箱无法安装"是因为包名 `p5.js` 拼错，正确是 `p5`）。
2. **p5.js 用 instance mode**：非 global mode（避免污染 window），用 `new p5(sketch, container)`，组件卸载时 `instance.remove()` 销毁。
3. **GSAP 插件注册**：ScrollTrigger 在每个使用文件顶部 `gsap.registerPlugin(ScrollTrigger)`，重复注册无副作用。
4. **Motion 仅用于 Hero 标题**：避免在 PostCard 等列表项大量使用 Motion（增加 bundle），Motion 集中投入首屏锚点。PostCard 入场保持用 Reveal。
5. **数据层保留**：types/post.ts、lib/stats.ts、lib/directus.ts 的 likes/comments 字段保留，避免破坏 Directus SDK 类型映射。仅清除 UI 层展示。
6. **reduce 模式全程守护**：
   - p5：`noLoop()` 只渲染一帧
   - GSAP：`matchMedia.add('(prefers-reduced-motion: reduce)', ...)` 不动画或直接 set 终态
   - Motion：`useReducedMotion()` + `initial={false}`
   - 纯 CSS hover：reduce 模式下 hover 倾斜可保留（不是动画，是状态切换，无运动不适感）
7. **动效动机审查**（design-taste-frontend §5）：
   - Hero 流场 → storytelling（海洋意象）+ hierarchy（首屏聚焦）
   - Hero 标题 stagger → hierarchy（逐字聚焦）
   - 打字机 → feedback（终端启动）
   - 滚动进度条 → feedback（阅读进度）
   - PostCard hover 倾斜 → feedback（物理感）
   - Footer 鲨鱼游动 → storytelling（鲨鱼游出海）
   - Timeline 竖线 → storytelling（时间推进）
8. **不做的动效**（避免 AI-slop）：
   - 不做满屏粒子背景（仅 Hero）
   - 不做鼠标跟踪磁
